```

├── core/          # Pure TS layout algorithms (no React)
```

## Key Architectural Patterns

- **Composable interfaces**: `GridConfig`, `DragConfig`, `ResizeConfig`, `DropConfig`
- **Pluggable strategies**: `Compactor`, `PositionStrategy`, `LayoutConstraint`
- **Immutable layouts**: `type Layout = readonly LayoutItem[]`
- **Two-layer constraints**: pixel preview (react-resizable) + grid-unit validation (core)
- **Performance**: CSS transforms default, `React.memo` on GridItem, fast O(n log n) compactors in extras
- **Edge auto-scroll**: `createEdgeScrollController` rAF loop in GridItem (walks up from the dragged node)
- **Touch external-drop adapter (#2281)**: document-level touch listeners on GridLayout; translates `touchmove`/`touchend` into the drop pipeline (shared `computeDropPosition` math in dropMath.ts)

## Recent Behavioral Changes (2026-08)

- GridItem wrapped in `React.memo` (shallow geometry compare) — consumers must memoize children
- `dragConfig.allowMobileScroll` threaded to `DraggableCore` (touch onClick fix)
- Edge auto-scroll during drag (finds scrollable ancestor from the dragged node, not offsetParent)
- `containerBounds.constrainSize` bounds resize in bounded grids (#1779: GridItem measures the container height per-resize)
- North/nw/ne resize anchors the bottom edge
- `correctBounds` clamps `y: Infinity` to layout bottom
- Wrap-mode collisions resolve horizontally during drag
- Touch external-drop adapter: document-level touch listeners translate `touchmove`/`touchend` into the drop pipeline; shared `computeDropPosition` (dropMath.ts) + `placeDroppingItem`/`commitDrop` dedup the desktop/touch paths (#2281, #2284)
- `onLayoutChange` suppressed while a dropping placeholder is active (mid external-drag) — fires once on the committed drop (#2219)
- Responsive data-grid re-seeding: `synchronizeLayoutWithChildren` re-seeds w/h from child data-grid when a breakpoint layout is generated by cloning (#2110)
- `ResponsiveReactGridLayout` forwards the `allowMobileScroll` flat prop (#2289; it previously rebuilt `dragConfig` without it)
- `useContainerWidth` accepts optional `debounceTimeout` (ms): trailing debounce on ResizeObserver updates, freeze mid-resize and snap on settle (#2254)
