## src/react/components/

### GridItem.tsx (~1000 lines)

Individual grid item. Integrates react-draggable + react-resizable.

**Exports:** `GridItem` (React.memo), `GridItemProps`, `GridItemCallback`, `ResizeHandle`

**Key behavior (2026-08):**

- Wrapped in `React.memo` with shallow comparator (x/y/w/h, grid config, allowMobileScroll, callbacks) — consumers must memoize children
- `allowMobileScroll` → `<DraggableCore allowMobileScroll={...}>` (fixes touch onClick suppression)
- Edge auto-scroll: `createEdgeScrollController(node)` in `onDragStart`, `feed()` in `onDrag`, `stop()` in `onDragStop`
  - Walks up from the dragged DOM node (not offsetParent) to find the nearest scrollable container
- `getConstraintContext(containerHeight?)` — resize handler measures the grid container (`node.offsetParent.clientHeight`) and feeds it into `containerBounds.constrainSize` so isBounded grids clamp resize to the visible container (#1779)

### edgeScroll.ts (NEW — 2026-08)

Auto-scroll rAF loop for drag near edge.

**Exports:** `EdgeScrollController`, `createEdgeScrollController(node)`

- Finds nearest `overflow: auto/scroll` ancestor (starts from the node itself)
- 50px edge threshold, 12px scroll step
- `feed(clientX, clientY)` starts/feeds the loop; `stop()` cancels

### dropMath.ts (NEW — 2026-08)

Drop-position computation shared between desktop drag-over and touch adapter.

**Exports:** `computeDropPosition(input): { newDroppingPosition, calculatedXY }`

- Pure geometry: gridRect → item centering → scroll offset (#2143) → clamp → calcXY
- Both `handleDragOver` and the touch adapter call it (no faked ReactDragEvent)

### GridLayout.tsx (~1350 lines)

Main grid component.

**Props:** `GridLayoutProps` (width, children, gridConfig?, dragConfig?, resizeConfig?, dropConfig?, positionStrategy?, compactor?, constraints?, layout?, droppingItem?, innerRef?, callbacks)

**Key behavior (2026-08):**

- **Shared drop pipeline**: `placeDroppingItem()` (create/update placeholder) + `commitDrop()` are shared by `handleDragOver` (desktop) and the touch adapter so the two event sources stay identical (#2284)
- `handleDragOver` delegates geometry to `computeDropPosition` (dropMath.ts)
- **Touch external-drop adapter (#2281)**: document-level `touchstart/touchmove/touchend/touchcancel` listeners translate touch on a `data-rgl-draggable` source into the drop pipeline. `dropConfig.touchEnabled` (default true), `touchDragSource` (default `[data-rgl-draggable]`). Uses `elementFromPoint` over-grid checks; commits via `onDrop`. Listener deps keep stable via ref mirrors (`onDropPropRef` synced in `useLayoutEffect`).
- **`onLayoutChange` suppressed mid-external-drag (#2219)**: the layout-change effect also guards on `droppingDOMNode` (symmetric with `activeDrag`) so the transient placeholder doesn't fire the callback; fires once on the committed drop
- North/nw/ne resize anchors bottom edge (newY applied, post-compact re-applied)
- `allowMobileScroll` threaded from `dragConfig` to GridItem
- Mount layout-change callback filters dropping placeholder (#2210)

### ResponsiveGridLayout.tsx (~490 lines)

Wraps GridLayout with responsive breakpoint support.

**Exports:** `ResponsiveGridLayoutWithRef` (forwardRef), `ResponsiveGridLayoutInner`, `ResponsiveGridLayoutProps`

**Key behavior (2026-08):**

- `forwardRef` wrapper merges ref → innerRef (v1 contract restoration)
- `synchronizeLayoutWithChildren` re-derives layout from children + data-grid; `reSeedFromDataGrid` flag re-seeds w/h/min/max from child data-grid when a breakpoint layout was generated by cloning another (#2110) — items added at a small breakpoint don't shrink on grow
- `findOrGenerateResponsiveLayout` generates missing breakpoint layouts (clones nearest + compacts, so gaps collapse — #1744 verified via component tests)

**Defaults:** breakpoints={lg:1200, md:996, sm:768, xs:480, xxs:0}, cols={lg:12, md:10, sm:6, xs:4, xxs:2}

## src/react/hooks/

### useContainerWidth.ts

- Options: `measureBeforeMount?`, `initialWidth?`, `debounceTimeout?` (ms, #2254)
- `debounceTimeout`: trailing debounce — width holds while the container resizes, commits the latest measured value once after it holds steady; timer cleared on unmount. Absent/0 keeps the immediate RAF-deferred path.
- Returns: `{width, mounted, containerRef, measureWidth}`
- Uses ResizeObserver with RAF defer, `Math.round` (sub-pixel safety)
- Measures content box (computed width, not offsetWidth)

### useGridLayout.ts

Core grid state management hook.

- Manages layout, drag/resize/drop state
- Immutable updates via cloneLayout, deepEqual comparison

### useResponsiveLayout.ts

Responsive breakpoint management hook.

- Tracks breakpoint, cols, layouts per breakpoint
- Public API but NOT used internally (ResponsiveGridLayout has its own copy)
